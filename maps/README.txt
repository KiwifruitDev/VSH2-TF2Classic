Due to a limitation with TF2 Classic, you must add custom items_game.txt and reslist files for each VSH map you're using.
These files define the bosses' weapons and the assets to be downloaded by clients.

Copy both (mapname)_items_game.txt and (mapname).res to the maps folder on your dedicated server.
Rename the files to replace "(mapname)" with the name of your map.

For example, the map "vsh_toys_b3.bsp" would require the following file names:
- "vsh_toys_b3_items_game.txt"
- "vsh_toys_b3.res"

If you're using Windows, make sure to enable "Show file name extensions" in File Explorer.

If you're updating this plugin, you will have to copy and rename the files again, as the new version may differ.
